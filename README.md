# بورس‌مگ — داشبورد بورس ایران

داشبورد نمایش داده‌های بازار بورس و فرابورس تهران (TSETMC).

## اجرای محلی (با سرور Node)

```bash
npm install
npm start            # http://localhost:3000
```

سرور Node به‌عنوان پراکسی TSETMC عمل می‌کند و به‌ترتیب از این منابع استفاده می‌کند:
داده زنده ← کش دیسکی (۲۴ ساعت) ← اسنپ‌شات Actions ← داده نمایشی (seed).

## دیپلوی روی GitHub Pages (بدون سرور)

دو workflow موجود است:

| Workflow | کار |
|---|---|
| `Deploy to GitHub Pages` (`.github/workflows/deploy.yml`) | روی هر push به `main`: اسنپ‌شوت TSETMC می‌گیرد → سایت استاتیک + `api/*.json` را در `dist/` می‌سازد → روی GitHub Pages منتشر می‌کند |
| `TSETMC live data snapshot` (`.github/workflows/snapshot.yml`) | هر ۱۵ دقیقه داده واقعی را در `data/live/` کامیت می‌کند؛ دیپلوی بعدی همان را منتشر می‌کند |

نیازمندی یک‌باره: در GitHub از مسیر
**Settings → Pages → Build and deployment → Source: GitHub Actions**
انتخاب شود (برای فعال‌سازی اجرای اول، یک‌بار دستی از تب Actions اجرا کنید یا روی push اعمال می‌شود).

نکته: در حالت استاتیک، داده‌های «تک‌نماد» (سفارش‌ها، سرانه خرید حقیقی/حقوقی و
تاریخچه نمودار) از ردیف جدول نمادها ساخته می‌شود و بدون سرور Node کامل نیست.

### داده زنده لحظه‌ای (اختیاری)

- **سرویس رایگان:** همان اسنپ‌شات Actions هر ۱۵ دقیقه (تأخیر ~۱۵ دقیقه).
- **زنده لحظه‌ای:** اسکریپت `relay/relay.js` را روی یک سرور/IP ایران اجرا کنید و
  آدرس آن را در متغیر `TSETMC_RELAY` تنظیم کنید — بدون هیچ تغییر دیگری در کد.
- **بدون نیاز به سرور (Serverless - رایگان):** شما می‌توانید از سرویس‌های رایگانی مثل **Cloudflare Workers** یا **Vercel** استفاده کنید تا درخواست‌های شما را به صورت پروکسی به TSETMC ارسال کنند:
  - **روش کلودفلر (پیشنهادی):** یک Worker در Cloudflare بسازید و کدهای داخل فایل `cloudflare-worker.js` (موجود در روت پروژه) را در آن قرار دهید. پس از دیپلوی، آدرس Worker را به عنوان متغیر `TSETMC_RELAY` در فایل `relay-config.json` یا به عنوان Secret در گیت‌هاب اکشنز (`PUBLIC_RELAY_KEY` / `TSETMC_RELAY`) تنظیم کنید تا مرورگر کاربران به جای سرورهای شما مستقیما با Worker صحبت کنند.
  - **روش ورسل (Vercel):** فایل `api/tsetmc-proxy.js` یک تابع Serverless برای ورسل است که می‌توانید در صورت دیپلوی روی Vercel از آن به عنوان یک پروکسی با ارسال آدرس درخواست به پارامتر `path` استفاده کنید. (مثلا `/api/tsetmc-proxy?path=/api/...`)
